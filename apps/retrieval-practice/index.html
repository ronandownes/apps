Revisit. Connect. Extend.

Recall the idea aloud, reveal it, then explain or justify it. Assess your own understanding.

Assessment as learning

Try to retrieve each idea before looking. Explain it in your own words, give an example or justify a claim. Compare your explanation with the reference. Mark it secure only if you can explain it independently. Otherwise, revisit it. Self-ratings are not automatic marks. They are stored only on this device when browser storage is available.
